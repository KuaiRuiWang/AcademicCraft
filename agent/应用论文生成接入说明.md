# 应用论文初稿与 Word 导出

在「创建应用」页勾选「同时生成毕业论文初稿」，可选填论文题目。应用生成后，在对话页的「论文初稿」标签查看进度、编辑章节、重试未完成章节和下载 Word。已有应用可在同一标签手动发起生成。

在「编辑本章」中选中一句话或一段正文，点「AI 修改选中内容」，填写要求并生成建议。对照原文确认后，点「替换选区」再保存本章。已有论文的正文也可这样修改，配图和代码块仍以原内容保存。

## 任务书和开题报告

项目创建者可以在项目对话页打开「任务书」或「开题报告」，根据项目题目和创建需求提前准备材料。选择内置模板或导入学校的 Word 模板后，页面列出将填写的栏目。点击生成后可离开页面，完成后可预览正文和下载 Word。

每个项目的两类材料各保存一份学校模板。支持 5 MB 以内的标准 `.docx` 文件。系统会识别常见的表格空栏和标题下的空段落。自定义栏目可在正文或表格中的目标位置写入 `{{研究内容}}` 等占位符。导出时沿用原表格、页眉和页脚，签字或审批意见留给本人填写。

存量数据库在启动前执行 [毕设材料迁移脚本](../sql/upgrade_graduation_documents.sql)。Word 填表复用下文的 Python 环境。管理员可在「步骤配置 → 毕设材料」分别为任务书撰写和开题报告撰写选择模型。

## 启用

已有论文表的数据库在启动新版后端前执行一次 [upgrade_thesis_references.sql](../sql/upgrade_thesis_references.sql)。还没有论文表的存量库使用 [upgrade_thesis.sql](../sql/upgrade_thesis.sql)，新库使用 [init.sql](../sql/init.sql)。检索词和章节写作使用管理端「论文 → 章节正文」的模型配置，默认使用普通流式模型（`streaming-chat-model`）。每章收齐响应后保存，等待上限为 180 秒。启动方式见 [快速开始](../README.md#快速开始)。

后端需能访问 OpenAlex 和 Crossref。可以设置 `OPENALEX_API_KEY` 或 `thesis.openalex-api-key` 提高 OpenAlex 配额。

## 参考文献

生成前按论文题目和项目资料检索候选文献，带 DOI 的条目用 Crossref 核验。绪论和相关技术从已核验的候选中引用，文末按正文首次出现的顺序生成 GB/T 7714—2025 条目。页面和 Word 共用编号与来源链接。

旧稿点击「重新生成未编辑章节」即可补查文献。在任意章节的编辑器里，把光标放在引用位置，选择文献后点「插入引用」，保存后可在「参考文献」核对来源。

## 安装 Word 导出工具

需要 Python 3.10 或更新版本、Node.js 22.12 或更新版本，以及 Chromium 和中文字体（例如 Noto Sans CJK）。在仓库根目录执行以下命令。

Windows PowerShell

```powershell
python -m venv tools/thesis/.venv
.\tools\thesis\.venv\Scripts\python.exe -m pip install -r tools/thesis/requirements.txt
npm ci --prefix tools/thesis
```

Linux 和 macOS

```sh
python3 -m venv tools/thesis/.venv
tools/thesis/.venv/bin/python -m pip install -r tools/thesis/requirements.txt
npm ci --prefix tools/thesis
```

Mermaid CLI 安装时会下载 Chromium。使用现有 Chrome 时，可在安装前设置 `PUPPETEER_SKIP_DOWNLOAD=true`，并通过 `PUPPETEER_EXECUTABLE_PATH` 指定浏览器可执行文件。

从仓库根目录运行时，后端优先使用 `tools/thesis/.venv`。单独部署 jar 时，可通过 `thesis.python-command` 和 `thesis.mermaid-cli` 配置 Python 与 Mermaid CLI 脚本的绝对路径。jar 已包含排版脚本，运行环境需随部署准备。

## 内容与版本

- 文稿包含中英文摘要、绪论、相关技术、需求分析、系统设计、系统实现、系统测试、总结与展望和待补材料。参考文献随正文引用生成。
- 生成依据来自应用源码、接口契约和数据模型。采集范围会排除依赖、构建产物、隐藏文件及 `.env`。版本快照保存在 `tmp/thesis/{appId}/{sourceVersion}/source-context.txt`。
- 章节独立保存，重试时继续未完成章节。应用修改开始时撤销旧任务版本，保存新章节时校验版本。手动编辑的章节保留原文并提示核对，保存编辑时会校验版本与原文。
- 任务独立于 SSE 连接。当前按单实例运行，重启后可恢复生成中的任务。多实例部署需要共享任务租约。
- 缺少真实执行记录时，测试结果标为「待验证」。根据实际运行情况补充截图和测试结论，并核对文献来源。
- Word 使用 A4 通用中文样式，包含标题、图片、表格、目录域和页码。使用 Word 打开后可更新目录，并按学校模板核对最终版式。
- 系统设计章节支持导出最多 8 张 Mermaid 图，使用本地图形与文字。图表语法或渲染依赖错误时，导出会返回错误。

## Diagram Design 配图

新生成的论文会先提取 Mermaid 草图的节点、关系、字段和时序，再由独立模型调用按 Diagram Design 的对应类型规范和模板绘制 SVG。配图支持架构图、流程图、ER 图、时序图和状态图；原有 Mermaid 初稿继续可以导出。旧论文点击「重新生成未编辑章节」后会采用新配图，手动编辑过的章节保持原文。

- SVG 与源图、图题一起保存为章节中的 `diagram-design` 块，无需新增数据库字段。
- 校验保留源节点、连线端点、ER 字段和边标签，并运行上游离线检查与几何检查。校验失败时带反馈修正一次，再次失败时保留原始 Mermaid 结构图，页面预览和 Word 都沿用本地渲染器。已保存的图题即使落在代码围栏内，预览和导出也会将它作为独立图题处理。
- 页面以图片文档预览 SVG，支持局部横向滚动和查看图中原文。编辑正文时配图显示为占位行，保存时恢复原图；删除占位行可移除该图。
- Word 导出将同一张 SVG 以三倍像素密度渲染为 PNG。继续复用现有 Python、Node、Puppeteer/Chrome 和中文字体，无需安装 Playwright。脚本和上游 MIT 声明包含在 jar 中。
- 配图只允许本地静态几何；不接受脚本、外部资源和内嵌 HTML。中文字体、字号和白底样式按论文用途适配。

## 第三方代码

Word 排版复用 `Doryoku1223/lunwen-skill`，配图复用 `cathrynlavery/diagram-design` 的规范、模板、提取器和校验工具。固定版本及 MIT 许可见 [第三方声明](../tools/thesis/NOTICE.md)。

## 验证

在仓库根目录运行 Java 服务和 Word 导出测试。Windows PowerShell 使用以下命令。

```powershell
.\mvnw.cmd '-Dtest=Thesis*Test,ProjectSnapshotServiceTest' test
.\tools\thesis\.venv\Scripts\python.exe -m unittest discover -s tools/thesis/tests -v
```

Linux 和 macOS 使用以下命令。

```sh
sh ./mvnw '-Dtest=Thesis*Test,ProjectSnapshotServiceTest' test
tools/thesis/.venv/bin/python -m unittest discover -s tools/thesis/tests -v
```

浏览器用例使用独立的测试接口。进入 `wang-ai-code-fronten/`，设置 `VITE_API_BASE_URL=http://127.0.0.1:18723/api` 后执行 `npm run dev -- --host 127.0.0.1 --port 5179 --strictPort`。另开终端进入前端目录，运行以下命令。

```sh
node tests/thesisPanel.browser.mjs
npm run test:thesis
```

用例从 Word 导出工具的依赖中加载 Puppeteer，需要已安装的 Chromium 或已配置的 `PUPPETEER_EXECUTABLE_PATH`。
